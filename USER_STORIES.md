# Triara — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Chief AI Officer

- As CAIO, I want pilots auto-registered when cloud cognitive spend appears, so that shadow AI cannot bypass the portfolio.
- As CAIO, I want scale requests blocked without verified ROI or a waiver, so that enthusiasm does not print money.
- As CAIO, I want a single scorecard across investment, risk, and talent pillars, so that steering debates use one truth.

### Cyber / risk officer

- As a cyber lead, I want production go-lives blocked on open critical AI cyber findings, so that vulnerabilities stop initiatives *before* incidents do.
- As a risk officer, I want ethics reviews attached to customer-facing models, so that ethical risk is not a footnote.

### LOB sponsor

- As a sponsor, I want clear gate statuses on my initiative, so that I know whether I am waiting on cyber, ethics, or talent.
- As a sponsor, I want claimed vs verified ROI shown distinctly, so that I do not oversell to my CEO.

### Talent / HR partner

- As HR, I want selector-role gaps visible beside engineer gaps, so that we hire for use-case judgement, not only ML ops.
- As HR, I want augment-vs-replace flags per initiative, so that workforce messaging matches reality.

### Finance

- As finance, I want ROI attestation with baselines, so that the median “48% ROI” culture cannot self-certify.
- As finance, I want learning-budget waivers explicit, so that experiments are funded honestly.
